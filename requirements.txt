# TopoDIM runtime dependencies (lean).

# This file previously held a full `pip freeze` of a Windows environment
# (271 lines, including pywin32/jupyter/gradio/tensorflow/selenium/poetry/
# google-cloud etc.), whose strict cross-pinned versions caused pip
# ResolutionImpossible (e.g. proto-plus needing protobuf>=4 vs a pinned
# protobuf==3.19.5). It has been trimmed to ONLY the packages TopoDIM
# actually imports, keeping each at its known-good version.
#
# torch / torch-geometric and the PyG C++ extensions are installed
# separately by the Dockerfile (CUDA-specific wheels), so they are NOT
# listed here.
#
# Transitive deps (scipy, scikit-learn, networkx, protobuf, ...) are
# intentionally left unpinned so pip can resolve a compatible set.
